# طرق المراقبة في PRTG

## 1. المراقبة السلبية (Passive Monitoring)
يستقبل PRTG البيانات التي ترسلها الأجهزة أو التطبيقات تلقائيًا، دون أن يقوم هو بطلبها.

### أمثلة
- **Syslog**: استقبال رسائل السجل من أجهزة Linux والراوترات.
- **SNMP Trap**: استقبال تنبيهات عند حدوث مشكلة.
- **Ping**: التحقق من أن الجهاز متصل بالشبكة.
- **Event Logs**: استقبال سجلات الأحداث من Windows أو Linux.
- **Bandwidth Data**: استقبال بيانات استهلاك الشبكة.

> **الفكرة:** الجهاز هو الذي يرسل البيانات إلى PRTG.

---

## 2. المراقبة باستخدام WMI
يستخدم PRTG بروتوكول **Windows Management Instrumentation (WMI)** لمراقبة أجهزة Windows.

### يمكنه مراقبة
- استخدام المعالج (CPU)
- استخدام الذاكرة (RAM)
- مساحة الأقراص (Disk)
- الخدمات (Services)
- العمليات (Processes)
- سجلات الأحداث (Event Logs)

### العيب
- يستهلك موارد الجهاز (CPU وRAM) بشكل ملحوظ.
- كثرة حساسات WMI قد تؤثر على أداء خادم Windows.

---

## 3. المراقبة باستخدام xFlow
يستخدم PRTG بروتوكولات **Flow** لتحليل حركة الشبكة.

### البروتوكولات المدعومة
- NetFlow
- sFlow
- jFlow
- IPFIX

### الفائدة
يعرض معلومات مثل:
- عنوان المصدر (Source IP)
- عنوان الوجهة (Destination IP)
- البروتوكول
- رقم المنفذ (Port)
- عدد الحزم (Packets)
- حجم البيانات (Bandwidth)

يساعد في معرفة **من يستهلك الباندويث** داخل الشبكة.

### Packet Sniffing
إذا كان الجهاز لا يدعم بروتوكولات Flow، يمكن لـ PRTG التقاط الحزم (Packets) وتحليلها مباشرة.

- أكثر تفصيلاً.
- يستهلك موارد أكثر من Flow.

---

## 4. المراقبة عبر HTTP
تستخدم لمراقبة:
- مواقع الويب
- خوادم الويب
- واجهات API

### يتم التحقق من
- توفر الموقع (Availability)
- زمن الاستجابة (Response Time)
- أكواد HTTP (200، 404، 500...)
- صلاحية شهادة SSL

---

# الملخص

| الطريقة | الاستخدام |
|----------|------------|
| **Passive Monitoring** | استقبال Syslog وSNMP Traps وEvent Logs وبيانات الشبكة. |
| **WMI** | مراقبة موارد أجهزة Windows مثل CPU وRAM وDisk. |
| **xFlow** | تحليل حركة الشبكة ومعرفة استهلاك الباندويث. |
| **Packet Sniffing** | تحليل الحزم مباشرة إذا لم تتوفر بروتوكولات Flow. |
| **HTTP Monitoring** | مراقبة المواقع الإلكترونية وواجهات API ووقت الاستجابة. |

## الفكرة الأساسية
يعتمد PRTG على أكثر من طريقة للمراقبة حسب نوع الجهاز أو الخدمة:

- **Windows Servers** → WMI
- **أجهزة الشبكات (Routers/Switches)** → SNMP / xFlow
- **المواقع وواجهات API** → HTTP
- **السجلات والتنبيهات** → Syslog / SNMP Traps / Event Logs2
